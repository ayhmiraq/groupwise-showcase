# Group Showcase Hub

انشئ لي تطبيق لمجموعة شركات مثلاً واجهة ويب ثابتة يكون فيها التوب بار و تحته هيدر يمكن تخصيص فديو خلفية للهيدر او للموقع بشكل عام دون التاثير على النصوص وعلى الوانها و يكون تحت الهيدر بطاقات صور وهي  تمثل الشركات التي تتبع هاذه المجموعة مقابل كل شركة اسم و تفاصيل مرتبطة بتسلسل زمني و تاريخ  .. يحتوي الموقع على الرئيسية و خدماتنا و مسيرتنا و المشاريع و المتجر و التواصل معنا.. كل صفحة منفصلة عن الاخرى و يمكن تخصيص التصميم مثلاً اضافة صورة خلفية او اضافة فديو يوتيوب خلفية .. يحتوي الموقع على لوحة تحكم متقدمة لادارة كل خيارات الموقع و اضافة منتجات للمتجر الذي سيكون منفصل بصفحة مستقلة عن باقي الصفحات و ايضاً اضافة مشاريع او تعديل مسيرتنا او تخيصيها او اضافة خدمات .. بعد اكمال التطبيق قم بمراجعة كاملة لكل الخصائص و اصلاح الاخطاء و تعديل النقوصات
