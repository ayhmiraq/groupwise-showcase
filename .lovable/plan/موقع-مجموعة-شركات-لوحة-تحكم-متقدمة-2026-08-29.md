# موقع مجموعة شركات + لوحة تحكم متقدمة

## الهوية البصرية
- خط Cairo (عربي/إنجليزي) عبر Google Fonts، محمّل من رأس التطبيق.
- لوحة ألوان أزرق داكن: خلفية `#0B1B33`، سطح `#122845`، أزرق أساسي `#2D6FA8`، لمسة فاتحة `#8FC1E3`، نص فاتح.
- كل الألوان كـ design tokens في `src/styles.css` (oklch) — لا ألوان مكتوبة داخل المكونات.
- دعم RTL/LTR: `dir` يتغير مع اللغة، ومبدّل لغة عربي/إنجليزي في التوب بار.

## الصفحات (كل صفحة مستقلة)
- الرئيسية: توب بار (تواصل سريع + لغة + سوشال) ثم هيدر/Hero بخلفية قابلة للتخصيص (صورة، فيديو مرفوع، أو فيديو يوتيوب) مع طبقة تعتيم تحفظ وضوح النصوص وألوانها.
- تحت الهيدر: بطاقات صور للشركات التابعة، لكل شركة اسم + وصف + تفاصيل مرتبطة بتسلسل زمني وتاريخ (صفحة تفاصيل لكل شركة مع Timeline).
- خدماتنا، مسيرتنا (Timeline زمني)، المشاريع، المتجر (كتالوج مستقل)، التواصل معنا.
- كل صفحة لها خلفية قابلة للتخصيص من لوحة التحكم + عناوين ووصف SEO خاص بها.

## المتجر
- كتالوج منتجات بأقسام، صفحة منتج، صور متعددة، سعر/عرض السعر.
- زر "طلب استفسار" يفتح نموذج (منتج + كمية + بيانات التواصل) ويُخزَّن كطلب في لوحة التحكم. لا بوابة دفع.

## لوحة التحكم (مدير واحد)
تسجيل دخول بالبريد وكلمة المرور، صلاحية admin مخزّنة في جدول أدوار منفصل. الأقسام:
- إعدادات عامة: اسم المجموعة، الشعار، السوشال، بيانات التواصل.
- تخصيص التصميم لكل صفحة: نوع الخلفية (صورة/فيديو/يوتيوب)، الرابط أو الملف، شدة التعتيم، تفعيل/تعطيل.
- الشركات: إضافة/تعديل/ترتيب + أحداث الجدول الزمني لكل شركة (تاريخ + عنوان + وصف).
- الخدمات، المشاريع، مسيرتنا: إضافة/تعديل/حذف/ترتيب/تخصيص.
- المتجر: أقسام ومنتجات وصور ومخزون بسيط.
- الرسائل وطلبات الاستفسار: عرض وتغيير الحالة.
- رفع الصور والفيديو عبر التخزين السحابي.

## التفاصيل التقنية
- تفعيل Lovable Cloud (قاعدة بيانات + مصادقة + تخزين).
- جداول: `site_settings`, `page_settings`, `companies`, `company_timeline`, `services`, `journey_events`, `projects`, `store_categories`, `products`, `product_images`, `inquiries`, `contact_messages`, `user_roles` + دالة `has_role`.
- RLS: قراءة عامة للمحتوى المنشور، والكتابة للمدير فقط؛ إدخال فقط لنماذج التواصل/الاستفسار. GRANT لكل جدول جديد.
- محتوى تجريبي (شركات، خدمات، مشاريع، منتجات، أحداث زمنية) يُدخل داخل الـ migration ليظهر الموقع مكتملاً.
- Routes منفصلة تحت `src/routes` (الرئيسية، services، journey، projects، store، store/$slug، companies/$slug، contact، admin/*) مع `head()` خاص بكل صفحة.
- لوحة التحكم تحت مسار محمي بالمصادقة؛ القراءات عبر TanStack Query + server functions.
- خلفية الفيديو: `<video autoplay muted loop playsinline>` أو iframe يوتيوب مع `pointer-events: none` وطبقة تدرّج، والنصوص فوق طبقة مستقلة لضمان التباين.
- بعد الإكمال: مراجعة شاملة لكل الصفحات ولوحة التحكم عبر متصفح تلقائي (تسجيل دخول، إضافة/تعديل، تحقق ظهور التغييرات)، وإصلاح أي أخطاء أو نواقص.

## خارج النطاق
